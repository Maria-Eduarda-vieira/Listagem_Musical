Sobre o Projeto

Este repositório contém o projeto de Sistema Musical, uma aplicação web front-end desenvolvida como atividade prática no curso de Desenvolvimento de Sistemas do SENAI "A. Jacob Lafer".

O sistema permite a navegação entre telas para gestão de artistas (criadores), cadastro de músicas (obras) e visualização de uma biblioteca completa com suporte a filtros de pesquisa. A interface foi planejada para garantir total acessibilidade tanto em dispositivos desktop quanto em celulares e tablets.

Objetivos Principais

Aqui está a lista das principais entregas da atividade:

✅ Desenvolver as 5 telas do tema: Login, Menu, Cadastro do Criador (Artista), Cadastro da Obra (Música) e Listagem (Biblioteca).

✅ Criar uma folha de estilo única (style.css) utilizando variáveis no :root com a paleta de cores do tema.

✅ Garantir responsividade total para funcionamento em computadores e celulares.

✅ Incluir o nome de todos os integrantes em comentário no topo do arquivo login.html.

✅ Subir o projeto com arquivos soltos na raiz de um repositório público no GitHub.
